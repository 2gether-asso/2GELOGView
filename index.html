❓ Aide & légende

Statuts
🔵 Prévu — l'événement n'a pas encore commencé.
🟢 En Cours — en train de se dérouler (pastille animée sur les tuiles).
⚪ Terminé — déjà passé.
Catégories & Types

Les Catégories regroupent les types d'événements définis dans la configuration (Jeux, Visionnage, IRL...). Les Types sont plus précis (Soirée Série, Meet Up, JDR...). Cliquez sur un bouton pour filtrer, sur "Annuler les filtres" pour tout réafficher.

Tags & Recherche

La barre de recherche (raccourci clavier /) filtre par titre, tag (#), organisateur ou plateforme. Les événements répétés (saisons, soirées hebdo) sont regroupés en une seule ligne dépliable dans les résultats. Si aucun organisateur n'est précisé, « Helldwin » est affiché par défaut.

Autres fonctions
🆕 Nouveau — événement ajouté au tableur depuis votre dernière visite.
🔗 Bouton dans la modale d'un événement — copie un lien direct vers celui-ci.
📅 .ics — télécharge le planning actuellement affiché pour l'importer dans votre agenda (Google/Outlook/Apple). C'est un export ponctuel, à réimporter manuellement si le planning change.
🔗 S'abonner — copie un lien d'abonnement (webcal://) vers le planning complet : à ajouter une seule fois dans votre appli calendrier, qui se resynchronise ensuite tout seul (régénéré côté serveur toutes les heures).
💬 Discord — copie un message prêt à coller dans un salon d'annonces, avec le programme des 7 prochains jours.
🔔 Rappels — sur n'importe quel événement, "M'envoyer un rappel" (dans sa modale) prévient par notification navigateur avant son début. Pour une série à plusieurs dates (hebdo ou notées), le même abonnement suit automatiquement chaque prochaine diffusion. Le bouton 🔔 Rappels de l'en-tête ouvre la liste de vos abonnements et un interrupteur global pour tout activer d'un coup.
📆 Période (Du/Au) — filtre le calendrier sur une plage de dates ; le lien ?today=1 n'affiche que les sessions du jour.
🎉 Rétrospective — bilan visuel de l'année (temps passé ensemble, catégories, MVP organisateur, mois le plus actif...), une année à la fois.
